Local Service Failed to Start / 本地服务未能启动

Please check if the installation is intact, and whether the data directory is occupied by another process.
请检查安装是否完整，以及数据目录是否被另一个独立服务占用。

Exit from the system tray and try again. Existing accounts and configuration will be preserved.
可从系统托盘退出程序后重试。已有账号和配置会保留。
